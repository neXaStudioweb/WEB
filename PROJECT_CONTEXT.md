# PROJECT_CONTEXT.md

## Proyecto

Nombre: Nexa Studio

Nexa Studio es un estudio de diseño web para negocios que quieren una presencia digital clara, estética y funcional.

El objetivo de la web es presentar la marca, explicar los servicios, transmitir confianza y facilitar que un cliente potencial contacte o solicite información.

## Identidad de marca

Nexa Studio debe transmitir:

- claridad
- criterio
- modernidad
- profesionalidad
- diseño premium
- sobriedad
- tecnología controlada
- confianza

La estética debe sentirse como “lujo silencioso tecnológico”: moderna, limpia, precisa y elegante, sin parecer ruidosa ni exagerada.

## Estilo visual

Mantener una estética:

- minimalista
- premium
- moderna
- sobria
- gris / blanco / negro
- con mucho espacio en blanco o espacio negativo
- tipografía limpia y fuerte
- animaciones sutiles
- microinteracciones elegantes
- posibles detalles 3D minimalistas, pero sin protagonismo excesivo

Evitar:

- colores neón
- estética gaming
- cyberpunk barato
- gradientes llamativos
- efectos exagerados
- animaciones con rebote excesivo
- scroll raro o molesto
- diseño genérico de IA
- secciones saturadas
- tarjetas repetitivas sin intención
- textos inflados o poco creíbles

## Tono de comunicación

El tono debe ser:

- claro
- profesional
- directo
- elegante
- cercano pero no informal en exceso
- orientado a negocios reales

Evitar frases genéricas como:

- “llevamos tu negocio al siguiente nivel”
- “soluciones digitales innovadoras”
- “diseño moderno y profesional” sin explicar nada
- estadísticas inventadas
- promesas exageradas

Preferir frases como:

- “Diseño web para negocios con criterio.”
- “Webs claras, estéticas y funcionales.”
- “Una presencia digital pensada para que el cliente entienda y actúe.”
- “Diseño con estructura, claridad y propósito.”

## Reglas de diseño

Antes de modificar el diseño:

- respetar la identidad actual
- no cambiar la paleta principal sin permiso
- no añadir efectos llamativos sin justificarlo
- no rediseñar secciones completas si solo se pide un ajuste
- mantener coherencia entre desktop y móvil
- cuidar espaciado, jerarquía visual y legibilidad
- priorizar claridad sobre espectáculo

Las animaciones deben ser:

- lentas
- suaves
- precisas
- discretas
- funcionales

El movimiento debe sentirse premium, no decorativo.

## Reglas técnicas

Trabajar de forma controlada:

- no modificar archivos innecesarios
- no reescribir toda la web sin permiso
- no instalar dependencias nuevas sin justificarlo
- no tocar configuración crítica sin permiso
- no tocar archivos .env, credenciales, tokens o claves
- no eliminar código sin explicar por qué
- hacer cambios pequeños y verificables

Si necesitas tocar varios archivos, primero explica cuáles y por qué.

## Stack previsto

El proyecto puede usar:

- React / Next.js
- Tailwind CSS
- Framer Motion / Motion
- Anime.js solo si aporta valor
- Playwright para revisión visual y funcional
- Hostinger / Vercel para despliegue según el caso

## Objetivo comercial

La web debe ayudar a captar clientes para servicios de diseño web.

Modelo previsto:

- proyecto web con pago único
- primer año de hosting incluido en el precio
- segundo año opcional:
  - el cliente puede seguir con gestión de Nexa
  - o puede solicitar migración a una cuenta propia

Nunca se comparten credenciales internas de Nexa.

## Servicios principales

Nexa puede ofrecer:

- diseño web para negocios
- landing pages
- webs multipágina
- integración de WhatsApp
- formularios
- reservas externas
- Google Maps
- enlaces a redes sociales
- diseño responsive
- optimización básica de velocidad
- marca personal deportiva como línea secundaria
- automatizaciones sencillas en fase futura

## Prioridades

Prioridad 1:
Lanzar la web de Nexa de forma limpia, estable y profesional.

Prioridad 2:
Usar la web como escaparate para captar primeros clientes.

Prioridad 3:
Crear un sistema repetible para futuras webs de clientes.

Prioridad 4:
Añadir herramientas de calidad como Impeccable, Playwright, React Best Practices y Systematic Debugging.

## Checklist antes de entregar o publicar

Antes de dar una tarea por terminada, revisar:

- versión desktop
- versión móvil
- header
- menú móvil
- botones principales
- formularios
- enlaces externos
- scroll
- legibilidad
- contraste
- errores de consola
- velocidad básica
- coherencia visual
- que no se haya roto ninguna sección existente

## Instrucción para Claude Code

Cuando trabajes en este proyecto:

1. Lee este archivo antes de hacer cambios.
2. Respeta la identidad visual y comercial de Nexa.
3. Haz cambios pequeños y controlados.
