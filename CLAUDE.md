# CLAUDE.md — Nexa Studio v2

## Antes de empezar

Lee siempre estos dos archivos antes de cualquier tarea:

- [PROJECT_CONTEXT.md](PROJECT_CONTEXT.md) — identidad, servicios, tono y reglas técnicas
- [DESIGN.md](DESIGN.md) — paleta, tipografía, animaciones, componentes y criterio visual

No hagas cambios hasta haber leído ambos.

---

## Flujos de trabajo

### Cambio grande o nueva sección
`brainstorming` → `writing-plans` → **aprobación del usuario** → `executing-plans` → `verification-before-completion`

### Cambio visual (UI, layout, componentes)
`frontend-design` → `ui-ux-pro-max` → `web-design-guidelines` → `executing-plans` → `verify`

### Animaciones o motion
`motion-design` → `css-animations` → `verify`

### Bug o error inesperado
`systematic-debugging` → plan → fix → `verification-before-completion`

### SEO o publicación
`web-design-guidelines` → `verification-before-completion` → `review`

---

## Restricciones críticas

No hagas ninguna de estas acciones sin permiso explícito:

- Cambiar paleta de colores, tipografía o identidad visual
- Rediseñar secciones completas (si solo se pide un ajuste, ajusta solo eso)
- Instalar librerías o dependencias nuevas
- Modificar `index.html`, `robots.txt`, `sitemap.xml` o archivos legales
- Tocar formularios, enlaces de contacto o rutas de navegación
- Eliminar código existente sin explicar el motivo
- Declarar métricas, clientes o claims que no existan realmente

---

## Checklist antes de publicar

- [ ] Desktop, tablet y móvil revisados
- [ ] Header y menú móvil funcionan
- [ ] Botones y formularios operativos
- [ ] Enlaces externos verificados
- [ ] Sin errores en consola
- [ ] `title`, `meta description`, `H1/H2` y `alt` correctos
- [ ] `robots.txt` y `sitemap.xml` intactos
- [ ] Coherencia visual respetada
- [ ] Ninguna sección existente rota
