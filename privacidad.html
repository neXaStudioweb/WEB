Política de Privacidad

Última actualización: mayo de 2026

Responsable del tratamiento

Nexa Studio
Correo electrónico: infonexastudioweb@gmail.com

Datos que recogemos

Este sitio web solo recopila los datos que el usuario proporciona voluntariamente a través del formulario de contacto:

  • Nombre
  • Correo electrónico
  • Mensaje

No se recopilan datos de forma automática ni se utilizan herramientas de analítica web ni publicidad.

Finalidad del tratamiento

Los datos facilitados se utilizan exclusivamente para responder a la consulta enviada y, si el usuario lo solicita expresamente, para enviarle información sobre los servicios de Nexa Studio. No se emplean para ninguna otra finalidad.

Base legal

El tratamiento de los datos se fundamenta en el consentimiento del interesado, prestado libremente al completar y enviar el formulario de contacto, de conformidad con el artículo 6.1.a) del Reglamento (UE) 2016/679 (RGPD).

Destinatarios

Los datos no se ceden a terceros, salvo a Web3Forms, servicio externo utilizado para la gestión y entrega de mensajes enviados a través del formulario. Web3Forms actúa como encargado del tratamiento bajo sus propios términos de privacidad y seguridad.

Conservación de los datos

Los datos se conservan durante el tiempo necesario para atender la consulta y, como máximo, durante el plazo legalmente establecido o hasta que el interesado solicite su supresión.

Derechos del usuario

En cualquier momento puedes ejercer los siguientes derechos sobre tus datos personales escribiendo a infonexastudioweb@gmail.com:

  • Acceso a tus datos
  • Rectificación de datos inexactos
  • Supresión de tus datos
  • Oposición al tratamiento
  • Limitación del tratamiento
  • Portabilidad de los datos

Reclamaciones

Si consideras que el tratamiento de tus datos personales no es adecuado, tienes derecho a presentar una reclamación ante la Agencia Española de Protección de Datos: aepd.es.
